# B3 correctness matrix

Static review of the 21 selected snapshots. Evidence and operation bodies are in each linked report, sections 1-7. No plugin code or tests were executed. Values describe supported source paths, not successful deployment or verified physical erasure.

`yes` in an adapter column includes confirmed/logical forget, not only hard delete. Engine `yes` means retained implementation at the engine or separately supplied SDK layer; the layer is named in each row. MindGraph has supplied SDK bodies but no server body. HydraDB has only an adapter-owned HTTP wrapper; Cognee has adapter HTTP/SDK call-through but no retained core. Their engine status is `not_in_repo`. Hindsight has working invalidation storage primitives and a CLI stub; its missing high-level orchestration is recorded in the report.

Derived `partial` means some live or indexed copies change while identified independent copies remain, or the full cascade is unverified. `unknown` means the external implementation prevents a grounded cascade verdict. No row establishes deletion from Hermes MEMORY.md, USER.md or state.db.

Reachable `yes` means a terminal process with the same available filesystem, endpoints and credentials can use the store independently of the plugin. It does not mean unauthenticated access, an encryption bypass or an allowed network connection through an egress guard. For Compartment and optionally encrypted mem-os, possession of ciphertext is not possession of the unlock key.

`profile .env` means `get_hermes_home()/.env`, normally `$HERMES_HOME/.env` or `~/.hermes/.env`. The host writer secures new files to 0600 but preserves an existing mode, including 0640. These are configured locations, not a claim that live keys exist there: `hermes-agent/hermes_cli/config.py:473`, `:506`, `:2538`, `:2711`. Other paths and plugin-specific modes are in section 4. No live credentials were opened.

Forget-test `yes` means at least one inspected test body exercises deletion/invalidation or its request contract at either adapter or engine layer. It is not a passing-test or coverage claim. Engine-only tests do not imply an adapter forget tool. Detailed counts are declarations with no parametrization expansion. Correction counts include explicitly named refinements of overly coarse B2 fields, not only reversed values.
